# Koshur Darbar — restaurant website

A single-page, self-contained website for Koshur Darbar Restaurant (Town Plaza, Kulgam, J&K).
Open `index.html` in a browser to preview — no build step.

## Before going live
Search `index.html` for these markers and fill in real details:

- `PHONE` — add the restaurant's phone number (Visit section + Wazwan enquiry button)
- `HOURS` — replace the hours row with actual opening times
- Menu — the dishes listed are classic Kashmiri / Wazwan dishes; swap in the real menu.
  To show a price, add `<span class="price">₹000</span>` as the last child of a `.dish-head`.
