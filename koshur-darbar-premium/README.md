# Koshur Darbar — premium landing page (agency pitch)

A single-page, self-contained premium redesign for Koshur Darbar Restaurant
(Town Plaza, Kulgam, J&K). Open `index.html` in a browser — no build step.

Distinct from the earlier `koshur-darbar/` site: deep green + saffron/gold +
cream palette, cinematic hero, signature-dish grid, gallery, testimonials,
and a sticky mobile call/book/directions bar. Built to show a client what a
premium redesign could look like.

## Before this goes anywhere public
Search `index.html` for these markers:

- `PHONE` — every "Call Now" / "Book a Table" / footer link uses a
  placeholder `tel:+91XXXXXXXXXX`. Replace with the real number.
- `HOURS` — the hours row currently links out to Google instead of stating times.
- `MENU` — dish descriptions are classic Kashmiri/Wazwan dishes with no
  confirmed prices; link "Ask About Our Full Menu" to a real menu once ready.
- `REVIEW` — the 4.7★ / 46-reviews figures and the three testimonials are
  **illustrative placeholders for this pitch**, not real Google data (the
  restaurant's actual public rating found during research was 4.4★). Replace
  with the real rating and real, permissioned review quotes before this is
  shown to the public.
- Photography — every "photo" (hero dish, gallery tiles, about scene) is an
  illustrated SVG composition, not a real photo. Swap in real food and
  interior photography for the final build.
